## Target geometries

The binary target geometries used in the demonstration notebooks are provided as NumPy arrays. The distributed arrays were generated or processed specifically for this work:

- **DTU logo:** generated from the Technical University of Denmark (DTU) logo. Information on the history and design of the DTU logo is available from [Teknologihistorie DTU](https://historie.dtu.dk/dtus-historie/navn-og-logo).
- **Disk:** generated programmatically as a simple test geometry.
- **Resolution test:** generated from the [resolution chart](https://github.com/TomographicImaging/CIL-Data/blob/efec5b0c8400725c67d6446f0ec7687783e5b1ed/resolution_chart.tiff) provided in the CIL-Data repository.
- **Gyroid:** generated by voxelising the *Gyroid cube* STL by S. Moczydlowski, available as [Thingiverse Thing 757884](https://www.thingiverse.com/thing:757884).

These target geometries correspond to those used in the accompanying publication.
